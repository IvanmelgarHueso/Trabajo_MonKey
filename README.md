# Cronostasis

Proyecto de Unity con la escena **Super Memory Numbers**, un juego de memoria numérica con ayudas y vidas.

## Abrir el proyecto

1. Añade esta carpeta a Unity Hub.
2. Ábrelo con la versión **Unity 6.6.2f1**.
3. Abre `Assets/Scenes/SuperMemoryNumbers.unity`.
4. Pulsa **Play** para iniciar.

Para previsualizarlo en vertical, selecciona una relación de aspecto 9:16 en la pestaña Game y maximiza esa pestaña si el panel queda estrecho.

## Repositorio

Se versionan los archivos fuente de `Assets`, `Packages` y `ProjectSettings`. La configuración de Git excluye las cachés, archivos temporales, registros y escenas de recuperación generadas por Unity.
